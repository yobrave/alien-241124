# Alien Field Notes: The Two Day Earth Review

One line, at most 200 characters: an alien tourist's review of planet Earth. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
